# UAV detection model

`best.pt` is the community model
[`TomSmail/drone-yolo-v1`](https://huggingface.co/TomSmail/drone-yolo-v1).

- Architecture: Ultralytics YOLOv8n detection
- Classes: `0 = quadcopter`, `1 = fixed-wing`

- Source file size: 12,351,474 bytes
- SHA-256: `bf24a20e69b28896a0c7e4855c72146149fa5c25845fa5e54beda2b93cf79824`

The published metrics are results reported by the model author. Performance on
the target camera and environment must be measured separately.
